
# 🧬 Deep Learning for Protein Function Prediction

## Overview

This project implements an end-to-end deep learning pipeline for predicting protein functions from amino acid sequences.

Models implemented:

- BiLSTM + Self Attention
- ProtBERT + MLP

The project covers:

- Data Exploration
- Data Preprocessing
- Sequence Encoding
- Deep Learning Model Development
- Evaluation Metrics
- ProtBERT Transfer Learning
- Prediction System
- Gradio Deployment
